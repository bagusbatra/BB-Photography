    Galeri

    Tambah karya

    Tampil sebagai keterangan lokasi di portofolio publik.
    Gunakan URL gambar publik atau path lokal, mis. assets/foto.jpg.

    Pratinjau

    Masukkan URL foto untuk melihat pratinjau.

    Rasio foto galeri 4:5.

    Galeri → publik

    Publikasikan galeri

    Unduh file data terbaru, lalu ganti js/gallery-data.js di folder situs.

    1. 1

      Unduh gallery-data.js lewat tombol di bawah.

    2. 2

      Ganti file js/gallery-data.js di folder situs dengan file hasil unduhan.

    3. 3

      Jalankan npm run build (atau biarkan GitHub Action bekerja) agar kartu statis dan JSON-LD galeri ikut diperbarui.

    4. 4

      Unggah ulang situs, lalu muat ulang halaman publik. Bersihkan cache/CDN bila perlu.

    Pratinjau halaman

    Pratinjau hanya membaca data lokal di browser ini. Tombol publikasi tidak bisa menulis file ke server, jadi langkah mengganti file tetap diperlukan agar pengunjung melihat karya baru. Setelah data diganti, npm run build menyegarkan kartu galeri dan schema ImageObject untuk mesin pencari; npm run check:gallery memeriksa apakah hasil pre-render sudah sinkron.

    Publikasikan konten

    Unduh file data terbaru, lalu ganti js/site-data.js di folder situs.

    1. 1

      Unduh site-data.js lewat tombol di bawah.

    2. 2

      Ganti file js/site-data.js di folder situs dengan file hasil unduhan.

    3. 3

      Jalankan npm run build agar kartu statis, pilihan form, dan JSON-LD ikut diperbarui.

    4. 4

      Unggah ulang situs, lalu muat ulang halaman publik. Bersihkan cache/CDN bila perlu.

    Pratinjau halaman

    Pratinjau hanya membaca data lokal di browser ini. Tombol publikasi tidak bisa menulis file ke server, jadi langkah mengganti file tetap diperlukan agar pengunjung melihat konten baru. Setelah data diganti, npm run build menyegarkan konten statis dan schema mesin pencari; npm run check:site memeriksa apakah hasil pre-render sudah sinkron.
